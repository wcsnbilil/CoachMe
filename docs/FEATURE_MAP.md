# 功能地图

从用户视角列出每个页面和功能：叫什么、从哪里进。沟通时用「叫法」这一列的名字。
代码位置只为方便定位，名字以界面上的文字为准；界面文字改了，这里跟着改。

App 有两个形态，由构建设置 `COACHME_BETA_MODE` 决定（现在默认是内测版）。上架的是完整版，内测版是临时形态。

## 内测版

只看下杆路径，离线，中英双语。界面文字在 `CoachMeCore/Sources/Beta/BetaStrings.swift`。

| 叫法 | 界面标题 | 怎么进 | 代码 |
|---|---|---|---|
| **内测首页** | 「CoachMe 内测版」；列表「我的分析记录」 | 打开 App | `Features/Beta/BetaRootView.swift` |
| **拍摄引导** | 「拍摄引导」 | 内测首页「开始新的分析」 | `Features/Beta/ShootingGuideView.swift` |
| **内测分析中** | 「正在本机分析…」 | 拍摄引导「我已录好，选择视频」 | `BetaRootView.swift` |
| **内测报告** | 「下杆手部路径」 | 分析完成后；或内测首页点一条给了结论的记录 | `Features/Beta/BetaReportView.swift` |
| **拒判页** | 「这段视频无法判断」 | 分析完成但无法判断时；或内测首页点一条拒判的记录 | `Features/Beta/BetaRefusalView.swift` |
| **3D 回放** | 「原机位 3D 回放」 | 内测报告里的按钮 | `Features/Beta/BetaReplay3DView.swift` |
| **内测设置** | 「设置」 | 内测首页右上角 | `Features/Beta/BetaSettingsView.swift` |

内测报告里的结论有四种写法：「手部路径未见明显外下或内下」「外下式手部路径」「内下式手部路径」「无法判断」；把握不高时标题换成「手部路径接近外下边界」「手部路径接近内下边界」，或加「结果仅供参考」。完整版报告页的结论是「手部路径在职业范围内」「外下式手部路径」「内下式手部路径」「无法判断」。
内测首页还有「导出测试记录」。
